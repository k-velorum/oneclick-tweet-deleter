# One Click Tweet Deleter

Xの自分の投稿に、赤いゴミ箱ボタンを追加するChrome拡張です。

- **クリック**：確認モーダルを開きます。X標準のボタン文言をそのまま残し、横にショートカットのY・Nをキー風に表示します。キーボードのYで削除、N・Escで中止できます。
- **Shift＋クリック**：確認を省略して削除します。削除した投稿は元に戻せません。

## インストール

1. このリポジトリの「Code → Download ZIP」からダウンロードして展開するか、`git clone https://github.com/k-velorum/oneclick-tweet-deleter.git` で取得します。
2. Chromeで `chrome://extensions/` を開き、デベロッパーモードを有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` があるフォルダを選択します。
4. Xのタブを再読み込みします。

ビルドは不要です。更新時は拡張機能の更新ボタンを押し、Xも再読み込みしてください。

## 対応範囲

日本語・英語のX（`x.com` / `twitter.com`）に対応します。ログイン中のプロフィールと投稿の著者が一致する場合だけボタンを表示します。引用先の投稿や他人のリポストは削除対象にしません。

X標準の削除メニューと確認画面を操作します。通信や認証情報の取得・保存、外部サーバーへの送信は行いません。削除の結果やエラーはX標準の表示で確認できます。Xの画面構造が変わった場合は、対応更新が必要になることがあります。

## 開発・検証

Node.js 22以上を使用します。拡張機能の利用だけならNode.jsやnpmのインストールは不要です。

`npm ci` → `npm run check` → `npm test`

DOMを模したテストで本人判定、Y/N確認、Shift操作、対象変更と誤操作防止を検証します。実環境では、本人の投稿へのボタン表示と通常クリックからのキャンセルを確認してください。実削除の検証は、削除してよい投稿だけで行ってください。

不具合は [Issues](https://github.com/k-velorum/oneclick-tweet-deleter/issues) に、Chromeのバージョン、Xの表示言語、再現手順を添えて報告してください。投稿内容や認証情報などの個人情報は含めないでください。
